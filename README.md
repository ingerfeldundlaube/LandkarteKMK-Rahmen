# LandkarteKMK-Rahmen

Interaktive Landkarte „Kompetenzen in der digitalen Welt“ zum
KMK-Kompetenzrahmen „Bildung in der digitalen Welt“; Aktualisierung im Kontext
Künstlicher Intelligenz (Beschluss vom 16.10.2026).

## Aufbau der Seite

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite mit der Landkarte (sechs Inseln, Mitte, Informationen) |
| `kompetenzbereich-1.html` … `-6.html` | Kompetenzen und Reflexionsfragen je Kompetenzbereich |
| `links-1.html` … `-6.html` | Weiterführende Links je Kompetenzbereich (noch leer, Vorlage im Quelltext) |
| `material.html` | Mitte: Aktualisierung 2026 – Unterstützungsmaterial |
| `informationen.html` | Informationen zur Landkarte |
| `style.css` | Farben und Gestaltung für alle Seiten |
| `dokumente/` | Kompetenzrahmen und Reflexionskarten als PDF |

## Links ergänzen

In `links-1.html` bis `links-6.html` steht im Quelltext ein Kommentar
„HIER LINKS EINFÜGEN“ mit einer Vorlage zum Kopieren.

## Veröffentlichen

Über GitHub Pages: *Settings → Pages → Branch `main`, Ordner `/ (root)`*.
